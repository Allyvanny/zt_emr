2. FEATURE ENGINEERING
   Raw logs are grouped into 60-minute rolling windows per user.
   For each window, 6 behavioural features are computed:
     1. records_accessed    - patient records opened in the window
     2. failed_logins       - number of failed actions/logins
     3. off_hours_flag      - 1 if activity is before 7am or after 8pm
     4. distinct_ips        - number of different IP addresses used
     5. actions_per_minute  - speed/intensity of activity
     6. after_midnight_flag - 1 if activity is between 12am-5am

3. MODEL
   Algorithm: Isolation Forest (unsupervised anomaly detection, scikit-learn)
   Why unsupervised: we do not have labelled 'attack' examples, so the model
   learns what NORMAL staff behaviour looks like and flags anything that
   deviates significantly as higher risk.

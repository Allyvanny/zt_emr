  1. Go to signup.sendgrid.com and create free account
  2. Verify your email address
  3. Go to Settings → API Keys → Create API Key
  4. Give it name Zero Trust EMR → click Create & Copy Key
  5. Paste the key below

Before you start:

  3. Search for "App passwords" on that page
  4. App name: type Zero Trust EMR → click Create

  6. Paste it below in the App Password field
